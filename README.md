# Bounce Back

Bounce Back is a quick one-player arcade game made with Python and Pygame. Move the paddle to return the ball, use the angle of each hit to send it across the table, and see how long you can keep the rally alive.

## Play

1. Press **Space** to serve.
2. Move the paddle left and right with **← / →** or **A / D**.
3. Catch the ball with the paddle to send it back. Hitting nearer an edge changes its direction.
4. If the ball gets past you, the rally ends. Press **Space** to start another one.

Your current rally and best rally are shown above the table. Press **Esc** whenever you want to close the game.

## Run the game

You’ll need Python and Pygame. From the folder containing `game.py`, run:

```bash
python -m pip install pygame
python game.py
```

## Controls

| Key | Action |
| --- | --- |
| ← / → or A / D | Move the paddle |
| Space | Serve or restart |
| Esc | Quit |

Good luck beating your best rally.
